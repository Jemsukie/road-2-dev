# Week 6 • Day 1: 📝 Project Planning

## Lecture Overview:
In this session, we will learn how to plan and design a web development project. You'll discover the importance of planning before coding, learn about wireframing, and create an outline for your personal portfolio website project. By the end of this lesson, you'll have a clear plan to guide your project implementation.

---

## Key Concepts:

### 1. Why Plan Before Coding? 🎯

Planning is crucial in web development because it helps you:
- **Clarify your goals**: Understand what you want to build
- **Save time**: Avoid rework and confusion during development
- **Stay organized**: Break down complex projects into manageable tasks
- **Set expectations**: Know what features to include and what to prioritize

**The Planning Process:**
```
1. Define the Project → 2. Plan the Structure → 3. Design the Layout → 4. List Features → 5. Create Timeline
```

---

### 2. Project Overview: Personal Portfolio Website 🌐

For this project, you'll build a personal portfolio website that showcases:
- **About Me section**: Introduction and background
- **Skills section**: Technologies and abilities
- **Projects section**: Showcase of your work
- **Contact section**: Ways to reach you

**Project Goals:**
- Create a responsive website that works on all devices
- Use HTML for structure, CSS for styling, and JavaScript for interactivity
- Make it visually appealing and easy to navigate
- Include interactive elements to engage visitors

### 4. Wireframing Basics 🎨

A wireframe is a simple visual guide that represents the layout of your webpage. It doesn't include colors or detailed design—just the structure.

#### Simple Wireframe Example:

```
┌─────────────────────────────────────┐
│         HEADER / NAVIGATION          │
│  [Home] [About] [Skills] [Contact]  │
├─────────────────────────────────────┤
│                                     │
│         HERO SECTION                │
│      "Welcome to My Portfolio"      │
│                                     │
├─────────────────────────────────────┤
│         ABOUT SECTION               │
│  [Image]  Text about yourself...    │
├─────────────────────────────────────┤
│         SKILLS SECTION              │
│  [HTML] [CSS] [JavaScript]          │
├─────────────────────────────────────┤
│         PROJECTS SECTION            │
│  [Project 1] [Project 2] [Project 3]│
├─────────────────────────────────────┤
│         CONTACT SECTION             │
│  Contact form or social links       │
├─────────────────────────────────────┤
│              FOOTER                  │
└─────────────────────────────────────┘
```

#### Tools for Wireframing:
- **Pen and Paper**: Quick and easy for simple projects
- **Online Tools**: Figma, Balsamiq, or draw.io
- **HTML/CSS**: Create a basic wireframe directly in code

### 6. Creating a Project Outline 📋

Here's a template for your project outline:

#### Project: Personal Portfolio Website

**1. Header/Navigation:**
- Logo or name
- Navigation links: Home, About, Skills, Projects, Contact
- Responsive hamburger menu for mobile

**2. Hero Section:**
- Large heading with your name
- Brief tagline or introduction
- Call-to-action button

**3. About Section:**
- Short bio about yourself
- Your photo (optional)
- Your interests and goals

**4. Skills Section:**
- List of technologies you know
- Visual representation (icons or progress bars)
- HTML, CSS, JavaScript, etc.

**5. Projects Section:**
- 3-5 project showcases
- Each project should have:
  - Project name
  - Brief description
  - Technologies used
  - Link or image (optional)

**6. Contact Section:**
- Contact form or
- Social media links
- Email address

**7. Footer:**
- Copyright information
- Additional links

## 🛠️ Hands-On Activity: Brainstorm and Outline Your Project

### Instructions:
1. **Create a new document** (text file or notebook) for your project plan.

2. **Define Your Project Goals:**
   - What is the purpose of your portfolio?
   - Who is your target audience?
   - What impression do you want to make?

3. **Create a Simple Wireframe:**
   - Draw or sketch the layout of your website
   - Include all major sections
   - Don't worry about details—focus on structure

4. **List Your Content:**
   - Write your "About Me" text
   - List your skills
   - Prepare project descriptions
   - Gather images (if needed)

5. **Plan Your Features:**
   - Essential features (must have)
   - Nice-to-have features (if time permits)

6. **Create a File Structure:**
   ```
   my-portfolio/
   ├── index.html
   ├── styles.css
   ├── script.js
   └── images/
   ```
