# Week 4 • Day 1: ✏️ Basics of JavaScript

## Lecture Overview:
In this session, we will cover the basics of JavaScript — the programming language of the web. You’ll learn about its syntax, how to declare variables, and understand different data types. By the end, you’ll be able to write basic scripts to manipulate and log data.

---

## Key Concepts:

### 1. What is JavaScript? 💡
JavaScript is a lightweight, interpreted programming language used to add interactivity and dynamic behavior to websites.

- **Why learn it?**  
  It’s one of the core technologies of the web, along with HTML and CSS. It allows you to build interactive elements like image sliders, dropdowns, and more.

---

### 2. JavaScript Syntax 🧾
JavaScript uses a syntax similar to other programming languages. Statements end in semicolons (`;`) and code blocks use curly braces (`{}` and `}`).

Example:
```javascript
console.log("Hello, world!");
```

---

### 3. Variables in JavaScript 📦

Variables are containers for storing data values. JavaScript uses `let`, `const`, and `var` for declarations.

```javascript
let name = "Alice";
const age = 25;
var city = "Manila";
```

- `let`: Block-scoped, can be reassigned.
- `const`: Block-scoped, cannot be reassigned.
- `var`: Function-scoped, older and less commonly used now.

---

### 4. Data Types 🔢

JavaScript has several basic data types:

- **String**: `"Hello"`
- **Number**: `42`, `3.14`
- **Boolean**: `true`, `false`
- **Null**: Represents intentional absence of value
- **Undefined**: Value not assigned yet
- **Object**: Complex data type, key-value pairs
- **Array**: A list of values

Example:
```javascript
let message = "Hello"; // String
let score = 100;       // Number
let isPassed = true;   // Boolean
let user = { name: "Alice", age: 25 }; // Object
let scores = [10, 20, 30]; // Array
```

## 🚀 Challenge: Basic Data Manipulation

1. Declare a variable `num1` and assign it a number.
2. Declare another variable `num2` and assign it a number.
3. Calculate the sum and store it in `total`.
4. Print out the result using `console.log()`.

```javascript
let num1 = 5;
let num2 = 10;
let total = num1 + num2;
console.log("Total:", total);
```
